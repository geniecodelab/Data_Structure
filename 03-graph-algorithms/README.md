# 03. 그래프 탐색 프로그램

파일에서 그래프를 읽어 인접 리스트 또는 인접 행렬로 저장하고, 여러 그래프 알고리즘을 명령어로 실행합니다.

## 구조
- `Graph`: 저장 유형(L/M)과 정점 수를 가진 부모 클래스
- `ListGraph`, `MatrixGraph`: 연결 정보 저장 (다형성으로 `PRINT`와 간선 조회를 구분)
- `GraphMethod`: BFS, DFS, Kruskal, Dijkstra, Bellman-Ford, Floyd, 근접 중심성
- `Manager`: `command.txt`의 명령어를 읽어 조율

## 입력 파일
1줄: 저장 유형(`L` 리스트, `M` 행렬), 2줄: 정점 수
- 리스트: 출발 정점 번호 한 줄 다음에 `도착정점 가중치` 줄들
- 행렬: 정점 수만큼의 줄에 가중치 (간선이 없으면 0)

## 명령어 (`O`는 방향 그래프, `X`는 무방향 그래프)
| 명령어 | 동작 | 오류 코드 |
|---|---|---|
| `LOAD 파일명` | 그래프 구성 (다시 LOAD하면 기존 그래프 삭제) | 100 |
| `PRINT` | 리스트 또는 행렬 출력 | 200 |
| `BFS O\|X 시작정점` | 너비 우선 탐색, 번호가 작은 정점 먼저 | 300 |
| `DFS O\|X 시작정점` | 깊이 우선 탐색 | 400 |
| `KRUSKAL` | 최소 신장 트리와 비용 (도달 불가 정점이 있으면 오류) | 500 |
| `DIJKSTRA O\|X 시작정점` | 모든 정점까지의 최단 경로 (음수 가중치면 오류) | 600 |
| `BELLMANFORD O\|X 시작 도착` | 최단 경로 (음수 가중치 허용, 음수 사이클이면 오류) | 700 |
| `FLOYD O\|X` | 모든 쌍의 최단 거리 행렬 (음수 사이클이면 오류) | 800 |
| `CENTRALITY` | 정점별 근접 중심성 (무방향, 가중치 고려)과 가장 높은 정점 표시 | 900 |
| `EXIT` | 메모리를 해제하고 종료 | - |

인자가 부족하거나 많은 경우에도 해당 명령어의 오류 코드를 출력합니다.

## 실행
```bash
make && make demo
```
`examples/`에는 8개 정점 그래프(`graph_L.txt`, `graph_M.txt`)와 음수 가중치(`graph_negative.txt`), 음수 사이클(`graph_negcycle.txt`) 그래프가 있고, `command.txt`가 이들을 차례로 불러 모든 명령어와 오류 경로를 실행합니다.

## 알려진 한계
근접 중심성은 어느 정점에서도 도달할 수 없는 정점이 있으면 모든 정점을 `x`로 출력합니다.
